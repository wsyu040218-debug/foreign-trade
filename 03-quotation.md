# 03 报价单｜CIF Hamburg / FOB Ningbo

**填写说明：** 第 6 天出初稿，第 7 天改到能直接粘进邮件。数字必须和 `02-factory-and-cost.md` 一致。下面英文是对外正文；中文是给你看的注释，发给客户时删掉中文。

**有效期 7 天** 写在第一屏。厨房套装海运一涨，CIF 就假了。

---

## 发给客户的报价（英文骨架）

Subject: Quotation KS-304-6 — 6pcs 304 utensil set, CIF Hamburg / FOB Ningbo

```
Hi [Name],

Thanks for the details. Please find our offer for the 6-piece 304 stainless steel kitchen utensil set, based on LFGB-capable production and neutral color box (your logo sticker or printed box).

Item: KS-304-6
Description: 6pcs kitchen utensil set (slotted turner, solid turner, ladle, skimmer, pasta server, slotted spoon)
Material: SUS304, satin finish, working end approx. 1.0 mm (to be confirmed on pre-production sample)
Packing: 1 set / PE bag / neutral color box; 12 sets / carton; palletized if required
Food-contact: LFGB test on this item before shipment (report in English). If a valid report for this item is already on file, we will send it with the PI.

Qty for this trial: 1 x 40'HQ, approx. 17,800 sets (final qty after carton size confirmation)

Price:
  USD 6.35 / set  CIF Hamburg
  USD 6.10 / set  FOB Ningbo

Payment: 30% T/T when order is placed, 70% T/T against copy of B/L
Lead time: 30 days after deposit and box artwork confirmed
Validity: 7 days (ocean freight)

Not included: German import duty, VAT, destination port charges, trucking. This is not DDP.

I recommend CIF Hamburg for this trial so you can compare with your own forwarder's FOB option. If you prefer to book the vessel yourself, use the FOB Ningbo line.

Two questions so we can lock the PI:
1) Sticker logo or printed box? (printed box MOQ 3,000 sets)
2) Do you need pallets? (I can quote both)

Best regards,
[Your name]
[WhatsApp / WeChat]
```

**报价说明（中文，勿发给客户）：** 先给 CIF 再给 FOB，让买家自己比货代。主动问彩盒和托盘，避免事后改价。不在报价里写「best price」「win-win」。

## PI 必填字段（不必另做合同全文）

下单前把报价升成 PI，下列字段缺一就不要让客户打定金：

| 字段 | 本单示例 |
| --- | --- |
| PI No. / Date | PI-KS-2026-001 / [date] |
| Buyer legal name + address | [公司全称], Hamburg |
| Description + item No. | 与报价完全一致，含 304、6pcs、盒型 |
| Qty + unit + total | 17,800 sets × 6.35 CIF Hamburg |
| Incoterms 2020 + named place | CIF Hamburg, Germany / or FOB Ningbo, China |
| Payment | 30% T/T to [bank], 70% against copy of B/L |
| Bank details | 公司账户，不要个人卡 |
| Lead time | 30 days after deposit **and** artwork confirmed |
| Inspection | 出货前你或第三方；费用谁承担写一句 |
| Documents | Commercial invoice, packing list, B/L, LFGB report copy |
| Tolerance | 数量 ±3%（整柜常用，需双方接受） |

LC 不写进本 PI。买家坚持 LC 时：先问条款能否为 at sight、单据清单是否只有常规 3 单 + 报告，再决定接不接。
