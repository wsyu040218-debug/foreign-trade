## 第 1 天必交：我怎么报 FOB / CIF（先写进这里）

教学口径（用自己的话改写 10 行，能口述即可）：

1. 工厂给我的通常是 **EXW 阳江 / 永康**，不含出门、不含出口港费用。
2. **FOB Ningbo** = 出厂价 + 内陆拖车到宁波 + 港杂 / 报关 / 码头操作（按柜分摊到每套）。风险在货物越过船舷（实务里按提单签发港理解即可）后转到买家。
3. 报 FOB 时我负责把货交到宁波港船上；海运费、德国清关、VAT、尾程都是买家的。
4. **CIF Hamburg** = FOB + 宁波到汉堡海运 + 途中保险。我安排订舱和保险，货到汉堡港后的滞箱、清关、VAT、派送仍是买家的。
5. CIF 不是门到门。买家说「送到仓库」是 **DAP/DDP**，两周内默认不报 DDP。
6. **DDP 的坑：** 德国进口 VAT（厨具一般 19%）、关税、EORI、尾程、查验。报错一口价会把利润吃光。回信策略：报 CIF，请对方用自己货代；若坚持 DDP，先要 EORI 和送货邮编，再另报价且加缓冲。
7. 大货付款默认 **30% T/T 下单，70% 见提单副本**。样品：T/T 或 PayPal，运费买家承担，大货可扣样费。
8. 信用证（LC）知道是银行信用，但不主动推：条款容易扣费、改证慢，新人容易把单证做丢。
9. 同一套货，FOB 数字一定低于 CIF；如果 CIF 看起来「没贵多少」，检查海运是否按整柜分摊、保险是否漏了。
10. 报价必须写港口。只写 FOB / CIF 不写 Ningbo / Hamburg，是外行。
